## Why this repository qualifies
Trend Emperor BTC Sentinel is an actively maintained, newly public BTC market-data research toolkit. It provides reproducible public-data ingestion, DuckDB pipelines, structural and Livermore analysis, walk-forward and overfitting checks, a credential-free read-only dashboard, and automated tests. I maintain its architecture, releases, tests, documentation, issue triage, and security. I am not claiming existing stars or downloads.

## Anything else
This is a safety-first open-source edition of a longer-running local project. Authenticated exchange clients, live execution paths, credentials, account data, and operational records are deliberately excluded. Codex Pro would help me sustain code review, testing, documentation, release work, dependency maintenance, issue triage, and security hardening as the public project develops.
