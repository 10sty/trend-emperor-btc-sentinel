# Security Policy

## Supported versions

Security fixes target the latest release on the default branch.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for this repository. Do not disclose a suspected vulnerability in a public issue before it is resolved.

Include a minimal reproduction, affected version or commit, impact, and suggested mitigation when possible. Never include credentials, `.env` contents, private account data, access tokens, or sensitive logs in any report.

## Project boundary

This repository accepts only unauthenticated public-market-data workflows. Authenticated exchange access and trade execution are intentionally out of scope. A contribution that weakens this boundary will not be accepted.
